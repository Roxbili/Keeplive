# Keeplive 设计

已确认：个人相册，照片保留在家中电脑或移动硬盘。家中电脑可以持续开机；未来通过服务器域名和手机浏览器访问。实现请求明确指定本目录，直接在此执行。

## 架构
Node.js 24 本地服务提供 React 网页及同源 /api 接口。SQLite 保存账户、会话、目录、媒体元数据与收藏。原目录只读，派生图像和 H.264/AAC 视频存储在独立 .data/cache 目录。根目录 ID + 相对路径确定媒体身份，换盘符不改变收藏和照片 ID。

域名服务器保存前端构建文件，Caddy 处理 HTTPS，通过 Tailscale 私有连接转发 /api 到本地服务。媒体经过服务器转发但禁止持久缓存。不自动安装或配置网络服务，不自动发布。

## 功能和界面
首次启动以终端展示的初始化码建立单用户账户。时间线、按文件夹浏览、收藏、搜索、LIVE 筛选；大图查看、切换、播放、声音、原图下载。手机优先布局，底部导航，桌面侧栏；冷白背景、石墨文字、蓝色操作、照片内容主导。标题使用本地衬线字体，操作用系统无衬线，不依赖外部字体。

目录设置支持绝对路径、递归扫描、重新定位、移除来源（只移除索引）。扫描优先元数据 ContentIdentifier 配对，只在标识不冲突且文件夹内名称唯一时回退同名配对。普通视频作为独立条目。已有文件通过大小和修改时间判断是否需要重读。扫描是后台任务；离线来源保留记录，访问失败给出可理解错误。

索引定时增量扫描（默认 10 分钟），手动扫描；素材首次访问时生成缓存，预热缩略图在扫描后执行。视频按需转码，支持 Range。认证保护所有媒体和索引，状态修改校验 Origin；不公开原路径，媒体文件实际路径必须在批准根目录中，拒绝符号链接绕过。

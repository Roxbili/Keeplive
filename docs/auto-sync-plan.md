# 照片自动同步实施计划

用户确认需要新增/删除照片自动出现，不是网页代码热更新。在现有索引和 3 秒状态同步基础上实施，不整页刷新，不丢掉当前查看的照片、选择或表单。

- [x] 新增 AutoSync：目录原生监听，1.5 秒合并变化，最多等待 5 秒；每 3 秒核对来源配置/连接并更新监听；默认每 60 秒补偿扫描。
- [x] 使用已有 Library.scan 串行扫描。等待在途扫描结束后再扫描，保留扫描期间产生的变化；停止时清理监听/定时器并等待正在执行的扫描。
- [x] 测试真实文件新增/删除、监听不可用、掉盘重连、配置改变及扫描期间再变化；不需要手动扫描触发。
- [x] 页面继续按版本局部更新；分享页只跟踪已分享内容的版本，不把新增私人照片加入分享，自动同步删除/修改和权限。
- [x] 将按钮说明改为自动同步与可选立即检查；构建/完整测试/浏览器新增删除演示/独立审查后更新本地服务和文档。

实施决定：查看器打开时保留当前缓冲影像和列表顺序，关闭后应用最新列表；当前照片已删除时关闭。选择清单按完整筛选 ID 集合清理，包含尚未加载的选择。临时断线继续重试，分享取消/到期则停止访客轮询。

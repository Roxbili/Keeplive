# Keeplive 隧道无窗口启动实施计划

> 使用 superpowers:executing-plans 在当前会话执行，按 TDD 验证。

**目标：**移除飞书桥接和 Keeplive 主服务的运行及自启动入口，保留并恢复 SSH 隧道。

**架构：**计划任务通过 GUI 子系统启动器运行 PowerShell，启动器和现有 Job 负责子进程生命周期；SSH 也使用 CreateNoWindow。保持原有远端、密钥和端口配置。

**技术栈：**Windows PowerShell 5.1、C#、Node.js 原生测试。

**需求来源：**用户在当前会话明确要求删除两个后台、保留 Keeplive SSH 隧道。

## 约束与验证重点

- 不删除项目、用户数据或密钥，不改 Codex Mobile 后台。
- 当前 Keeplive 目录不是 Git 仓库；修改前复制部署脚本和任务 XML 到本机维护备份，不初始化仓库或推送无关仓库。
- 不弹终端；带空格和中文的路径、引号参数保持准确；退出码传递；停止父进程后回收子进程。
- SSH 认证、远端监听和本机目标服务分别验证。3210 当前无人监听，不能把隧道连通称为应用已恢复。

# Keeplive 无登录开机运行计划

**需求：**Windows 更新重启后未登录时，照片后台与 SSH 隧道仍须运行。

**已查证：**两个现役任务均为 Interactive + LogonTrigger。当前 Codex 非管理员，临时注册 BootTrigger 探针返回 Access is denied，未改动现役任务。

**方案：**提供本机管理员转换脚本，将现有两个任务原位改为 BootTrigger + Password。保留当前账号、普通运行权限、GUI 启动器、动作、设置和数据；账户密码由本机 Get-Credential 收集，仅交给 Windows 任务计划程序，不写日志。避免 S4U 的网络及加密文件限制。

- 执行前：现役服务保持运行；测试只转换 XML，不注册真实任务。

# Keeplive 独立账号系统 · 2026-10-05

用户确认：每个账号有自己的照片目录和收藏。继续在当前项目内实现，保留已有相册及媒体功能。

## 功能
- 首次在服务所在电脑的本机页面创建管理员，填写用户名、显示名称、密码与确认密码，不再输入初始化码。代理和远程访问不能抢先创建管理员。
- 日常用户名/密码登录；个人资料、修改密码、退出登录。
- 管理员创建账号，分配角色和可使用的照片根目录，编辑名称、停用/启用、重设用户密码。保护最后一名有效管理员。
- 用户管理自己获准根目录中的照片来源；目录、列表、媒体、下载、收藏、统计、文件夹、扫描反馈均按用户隔离。
- 管理员在相册界面也只浏览自己的照片，账号管理不提供其他用户照片浏览入口。

## 存储与权限
SQLite 新增 users、user_favorites；sessions 增加 userId，sources 增加 ownerId。照片的 sourceId 即其所有权，所有接口从当前会话读取 userId，忽略客户端伪造的所有者。
普通用户只能在管理员分配的 allowedRoots 下添加来源。实际路径解析后再校验范围，拒绝跨账号目录重叠、父目录包含和符号链接绕过。管理员的初始账号可以配置可用目录，但同样不能通过相册来源覆盖其他用户已分配目录。
修改根目录权限不得把已有来源排除在外；先在本人相册移除或重定位来源。停用、角色/权限调整及密码重设撤销会话；修改本人密码撤销其他会话并重新签发当前会话。

## 兼容与验证
已有单密码账户自动迁移为 admin 用户，保留密码哈希、来源归属和收藏；老会话归属到迁移用户。无旧账户的旧来源在首次管理员创建时归属管理员。新增字段和迁移保持幂等。
测试本机首次创建、拒绝代理抢先设置、登录、角色校验、最后管理员保护、改密及停用会话撤销、资料验证、按用户收藏、跨账号源/照片/媒体访问、根目录逃逸、旧版迁移。浏览器使用独立验收数据验证界面，正式管理员账号由用户创建。

# 批量分享设计

用户已批准：批量选择照片，生成免登录只读分享相册，默认 7 天、可选 1/30 天或永久；原文件下载默认关闭。桌面左下角与手机设置提供我的分享管理。可复制链接、更新有效期/下载设置、撤销、重新生成密钥使旧链接失效。

照片清单固定，不随目录新增扩展。原文件不复制。删除来源/照片后从分享中排除，账号停用后全部分享停止后续访问。已经加载或保存的内容无法收回。照片仍由家中服务提供，外部访问需要已配置的 HTTPS 域名，未部署时界面说明本地链接范围。

访问链接 /s/<id>#<secret>；secret 为 32 随机字节 base64url。前端在同源 POST 中换取独立、HttpOnly、按分享 API 路径隔离的访问 Cookie，不用账号 Cookie。每次读取媒体及转换完成后验证密钥哈希、到期、撤销、活跃所有者、照片归属和下载权限。共享凭证不开放任何私人 API。响应 no-store/no-referrer/noindex，并限制访问请求频率。

SQLite 保存 shares 与 share_items。访问密钥保存 SHA-256 校验值，另用独立 .data/share.key 下的 AES-256-GCM 加密副本让所有者再次复制链接；加密副本绑定分享及所有者，不保存明文密钥。备份数据库与 share.key。无法解密副本时仍可撤销/换新密钥。

批量选择用照片 ID，支持月份选择及整个当前过滤结果（轻量 ID 接口）。跨账号、未知或重复/非法输入必须完整校验；不因部分非法项而分享其余项。切换账号清除选择及过期异步响应。公共相册独立于登录流程，提供分页、只读大图、实况播放、声音控制和允许时的原文件下载。

验证：无账号 Cookie 可访问、访问其他分享/非选中照片失败；关闭下载时所有原文件路径拒绝；撤销、到期、换密钥、停用、删除后拒绝，转换等待中撤销也拒绝；分享读写仅所有者可用；访问返回不泄露目录、用户权限或密钥；手机多选/分享/访客浏览验收。

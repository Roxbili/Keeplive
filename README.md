# Keeplive

留住每一刻。一个由家中电脑提供照片、可以通过网页浏览的私人相册，支持普通照片、视频和 iPhone 实况图。

## 在这台电脑上启动

需要 **Node.js 24 或更高版本**。Windows 下双击 `start-keeplive.cmd`，保持启动窗口运行，打开 **http://127.0.0.1:3210**。

首次打开，在运行相册的这台电脑上创建 **管理员账号**，填写用户名、显示名称和至少 8 个字符的密码。不需要初始化码，也不会预设密码。之后使用用户名和密码登录。远程地址不能创建第一个管理员。

电脑侧边栏进入「照片来源」（手机进入「设置 → 照片来源」），点击「添加目录 → 点击选择文件夹」，在运行 Keeplive 的 Windows 电脑上，通过 localhost 或 127.0.0.1 访问时，优先打开系统文件夹选择窗口，选完后点击「保存并扫描」。取消系统窗口会保留已有路径，也可点击「使用网页选择」。手机、其他电脑、域名或代理访问使用网页目录选择器，打开照片所在的目录后点击「选择这个文件夹 → 保存并扫描」。名称自动使用文件夹名，无需填写路径或目录名称。普通用户只显示被授权的目录；手机访问时选择的也是家中电脑上的文件夹。可以添加多个来源、扫描子文件夹，也可以在硬盘盘符变化后重新选择同一来源的路径。

终端方式：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

照片路径不需要写入源代码。原图只读，索引、账户、收藏和缓存默认保存在 `.data/`，已从版本控制排除。请备份原始照片以及 `.data/keeplive.sqlite`（停止服务后复制，或连同 WAL/SHM 一起备份）。浏览缓存可以重新生成；相册不是照片备份工具。

## Windows 自动启动

照片后台只通过一个 `Keeplive-<用户 SID>` 计划任务自启动，不另加注册表或启动文件夹入口。该任务使用 GUI 启动器，PowerShell 和 Node 均不分配控制台窗口；SSH 隧道由独立的 `Keeplive-Tunnel-<用户 SID>` 任务负责。安装后直接访问本机网页，无需再次双击手动启动脚本。

默认安装方式是**登录后启动**，Windows 更新重启后停留在登录界面时不会运行。需要**无需登录的开机启动**时，以安装 Keeplive 的同一账号打开管理员 PowerShell，执行 `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File "C:\Users\Fanding\Projects\Keeplive\deploy\windows\enable-boot-startup.ps1"`。脚本将现有照片与隧道任务原位改成开机 30 秒后启动，保持普通运行权限，并在本机提示输入 Windows 账户密码（不是 Hello PIN），由 Windows 任务计划程序保存。不会要求自动登录，也不会主动重启电脑；取消输入或转换失败时保留/恢复原配置。现役进程保持运行，未登录启动须在下一次重启后验证。账户密码修改后需重新执行转换以更新任务凭据；再次运行普通安装脚本会恢复登录触发，需要重新执行转换。

双击 `enable-autostart.cmd` 注册当前账号的 Windows 计划任务并立即启动。之后每次登录 Windows，会在后台启动 Keeplive，不需要保持 Codex 或终端窗口打开。任务以当前用户的普通权限运行，不需要保存 Windows 密码；仅本次脚本进程使用 RemoteSigned 执行策略，不修改系统策略。已安装依赖和构建文件需要保留，不会每次启动重新安装或构建。

后台服务退出时，启动器每 5 秒尝试重启；同一 Windows 登录会话中，一个项目只运行一个后台启动器。任务没有运行时间上限，也不会因为使用电池而停止。运行日志在 `.data/logs/server.log`、`.data/logs/server-error.log` 和 `.data/logs/autostart.log`；前一次运行的输出保留在对应 `.previous` 文件，启动器日志超过 10 MB 时在下次启动轮换。自动启动状态可在 Windows「任务计划程序」查看，任务名以 `Keeplive-` 开头；禁用或删除任务可关闭以后自动启动。在任务上选择「结束」会同时停止相册及其转码子进程；单独结束 Node 会触发自动重启。

这是**登录 Windows 后自动启动**，锁屏时继续运行；注销、关机或休眠时相册不可访问。保持当前 Windows 用户登录，电脑在线并避免自动休眠。此方式保留原生文件夹选择窗口的桌面环境。项目移动位置或 Node.js 安装路径变化后，需要停止原任务，再重新运行 `enable-autostart.cmd`。更新服务端代码后，结束原任务及对应 Node 进程，再启动任务；前端变更先执行 `npm.cmd run build`。

## 已实现

- 按拍摄时间浏览、文件夹相册、收藏、文件名/目录搜索、实况与视频筛选。
- 手机网格和底部导航，左右滑动切换大图，桌面方向键与 Escape 操作。
- 打开实况图时自动播放一次，结束后回到静态照片；支持暂停、重播和声音开关，原始照片和实况视频分别下载。
- 「设置 → 播放设置」分别控制实况和视频的声音，默认打开，按账号保存并在登录时读取。播放界面的声音按钮只调整当前播放。浏览器若限制有声自动播放，实况会暂时静音继续播放，并提示点击声音按钮开启，不修改账号设置。
- 「播放清晰度」同时用于实况和视频，默认原始清晰度（保留源分辨率）；可选高清（最长边 1920 像素）、流畅（最长边 1280 像素）。较小的视频不会被放大，各档位使用独立缓存，切换后下次打开动态内容即生效。设置按账号保存；匿名分享使用默认原始清晰度，不读取分享者的偏好。原始档仍生成兼容网页的 H.264/AAC 副本，不是无损播放；首次转换可能更久、占用更多缓存与网络流量，原文件完整保留。
- HEIC/HEIF 图像生成 JPEG 浏览副本，视频生成 H.264/AAC MP4；素材生成期间有加载反馈，转换结果缓存在电脑。
- 目录初次扫描后自动监听新增、修改和删除，通常几秒内同步到网页；默认每 60 秒补偿检查，监听不可用时也能恢复。可选“立即检查”；文件大小和修改时间未变时复用元数据。
- 硬盘离线保留已有索引和收藏；已生成的缩略图在家中电脑在线时仍可读取。硬盘换盘符后重新定位同一来源，照片编号保持不变。
- 独立个人账号：每个人的照片来源、照片列表、相册、收藏和扫描状态互相隔离。照片、视频、原文件下载和索引都需要登录。
- 管理员可创建账号、分配可用照片目录、调整角色、停用/启用账号与重置密码。普通用户只能使用管理员授予的目录和子文件夹；跨账号重叠目录会被拒绝。
- 「我的账号」支持修改显示名称和密码。密码、目录权限、角色或状态变化会让旧会话失效；至少保留一个可用管理员。默认会话有效期为 30 天。

Live Photo 应保留静态照片和对应 MOV 视频。优先根据 `ContentIdentifier` 配对；没有完整关联信息时，使用同目录内唯一、标识不冲突的同名文件辅助配对。同名但不相关的图像和视频仍可能无法准确判断，请保留原始导出文件及元数据。只有静态图时无法恢复实况。

转码生成的是用于浏览的副本；HDR、广色域、苹果编辑效果可能与系统相册存在差异。原始文件完整保留。代码和测试使用生成的图像/视频；需要用你自己的 iPhone HEIC/MOV 样本完成实际素材验收。

## 多人相册怎么用

管理员从电脑侧边栏进入「账号管理」（手机进入「设置 → 账号管理」），为家人创建账号并分配已存在的文件夹，例如 `E:\照片\家人`。每行填写一个完整目录路径。家人登录后，可以添加这个目录或其中的子文件夹，并建立自己的收藏。管理员的照片库也只展示自己的照片，账号管理页不提供其他人的照片浏览。

创建账号时可以暂不分配目录，稍后编辑账号再补充。停用账号会保留照片记录和收藏；重新启用后可以继续使用。当前版本由管理员创建新账号，没有开放公众注册。忘记密码时由另一位管理员重置；请妥善保存第一个管理员的密码。

旧版本的单密码相册会自动升级为用户名 `admin`，原密码不变，原有目录和收藏归这个账号。升级只执行一次。升级后的数据库包含用户系统字段，回退旧版程序前应恢复升级前的数据库备份。

## 配置

复制 `.env.example` 为 `.env` 后按需修改。更改配置后重启。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 默认仅本机访问；局域网访问可设为 `0.0.0.0`，并将防火墙访问限定在家庭网络 |
| `PORT` | `3210` | 服务端口 |
| `DATA_DIR` | 项目内 `.data` | 索引和派生素材目录，不能位于已添加的照片来源内 |
| `SCAN_INTERVAL_SECONDS` | `60` | 自动同步补偿检查间隔，最小 60 秒 |
| `PUBLIC_ORIGIN` | 未设置 | 对外域名，如 `https://photos.example.com`；设定后只能从这个来源修改相册 |
| `COOKIE_SECURE` | 未设置 | 域名 HTTPS 部署设 `1`；此时应通过 HTTPS 登录，普通 HTTP 不会携带登录 Cookie |
| `TRUST_PROXY` | 未设置 | 可选，精确指定可信代理地址；不要设成通配或信任所有客户端 |
| `FFMPEG_PATH` | 随依赖安装 | 可选，自定义 FFmpeg 路径 |

扫描期间禁用目录修改，以免出现不一致。硬盘断开会标记为未连接，重新连接后自动恢复同步；子文件夹无法读取时标记为部分读取并保留旧记录。移除来源只移除索引和该来源收藏，不删除硬盘照片。缓存目前不会自动清理，需要时可停止服务并删除 `.data/cache/`，保留数据库。

## 未来通过域名访问

设计是 **浏览器 → 域名服务器 → 加密私有网络 → 家中相册服务 → 本地硬盘**。域名服务器放网页构建文件，转发媒体但不保存照片库。电脑休眠、关机或家庭网络断开时，域名页面仍能打开并显示离线提示，无法读取照片。

推荐部署步骤：

1. 家中电脑与域名服务器安装 Tailscale，加入同一个私有网络。先验证两个设备之间的连通性和实际传输速度，家庭宽带上行与中继质量会影响播放。
2. 家中电脑继续将 Keeplive 绑定 `127.0.0.1:3210`。通过 **Tailscale Serve** 在私有网络内发布这个本地服务：`tailscale serve --bg http://127.0.0.1:3210`。按提示启用 tailnet HTTPS。
3. 配置私有网络访问规则，仅允许域名服务器访问家中电脑的相册端口。不要对这个服务启用公开 Funnel，也不要在路由器公开相册端口。
4. 在家中 `.env` 设置 `PUBLIC_ORIGIN=https://你的相册域名` 与 `COOKIE_SECURE=1`，重启。请先在本机创建管理员；启用后日常使用 HTTPS 域名访问。
5. 将构建后的 `dist/` 复制到服务器 `/srv/keeplive/dist/`。配置域名解析，安装 Caddy，将 `deploy/Caddyfile` 中域名、家中 Tailscale HTTPS 地址及路径改成实际值。
6. 启动 Caddy。手机直接访问 HTTPS 域名并登录，不需要安装 Tailscale。每次更新前端，需要重新构建并更新服务器上的 `dist/`；服务端代码更新在家中电脑执行。

示例配置没有媒体持久缓存。家中电脑的本地转换缓存及浏览器必要的内存播放缓冲仍会使用。Caddy 终止外部 TLS，再经私有加密连接读取家中内容。

以上配置是部署准备，尚未连接真实服务器、绑定域名或发布。上线前需验证 HTTPS Cookie、访问规则、代理的视频 Range、家中服务离线状态和 iPhone Safari 播放。

参考：[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)、[连接类型](https://tailscale.com/docs/reference/connection-types)、[Caddy HTTPS](https://caddyserver.com/docs/quick-starts/https)。

## 批量分享

在照片列表点击「选择」，可逐项勾选、选择整个月份，或「全选」当前筛选结果（包含尚未加载的照片）。底部点击「创建分享」，选择有效期（默认 7 天，可选 1/30 天或永久）和原文件下载权限（默认关闭）。生成后复制链接，访客无需账号密码即可查看选中的照片和视频、播放实况。单次分享最多 50,000 项，照片清单固定，不会自动纳入以后新增的文件。

电脑左下角进入「我的分享」，手机进入「设置 → 我的分享」。可再次复制链接、调整有效期和下载权限、换新链接或取消分享。到期/撤销/账号停用后，停止后续读取；换新链接会使旧访问凭证失效。移除照片或来源后，对应照片从分享排除。关闭原文件下载不能阻止截图或保存已经展示的内容。

访客可在分享页或实况/视频大图中选择原始、高清、流畅清晰度，选择保存在当前浏览器，不需要账号，也不改变分享者的设置。下载统一为一个按钮：实况照片下载一个 ZIP，内含未经修改的原始图片和对应视频；普通照片和视频直接下载各自原文件。分享下载仍需要分享者开启原文件下载权限。

链接密钥位于 `#` 后，通过同源请求换取只用于该分享的 HttpOnly Cookie。分享接口每次读取媒体、以及转换完成后均重新验证权限，私人接口仍要求账号登录。数据库只保存访问密钥哈希及加密副本；**备份时同时保留 `.data/keeplive.sqlite` 和 `.data/share.key`**。丢失 share.key 后旧链接仍可按哈希验证，但无法再次复制原链接，需要换新链接。不要公开 `.data` 或 share.key。

本地 `127.0.0.1`/`localhost` 链接只能在运行相册的电脑打开。外部分享需先按前面的部署步骤配置 HTTPS 域名；设置 `PUBLIC_ORIGIN` 后，创建的分享链接会使用该域名。家中电脑需保持在线。服务器的分享页面及全部分享 API 使用 no-store/no-referrer/noindex；真实服务器、域名和 iPhone Safari 尚未验收。

## 开发与检查

```powershell
npm.cmd run dev
# 本地前端：http://127.0.0.1:5173
npm.cmd test
npm.cmd run check
npm.cmd run build
```

前端 React + TypeScript + Vite，服务端 Express + Node 内置 SQLite，媒体通过 ExifTool、Sharp、HEIC 解码器及 FFmpeg 处理。全部浏览资源由自己的服务提供，不依赖在线字体或远程图片。




自动同步会局部更新照片列表、相册数量和分享页面，无需点击更新或重新加载网页。查看大图时保留当前照片和播放状态，关闭后展示最新列表；当前照片被删除时关闭查看器。删除的照片会自动移出批量选择。分享只同步原先选中的照片，不会纳入新增私人照片。电脑和相册服务需保持运行。

大图中的删除按钮或批量选择后的“删除”会将原文件移到照片所在硬盘的 `.keeplive-trash/<记录编号>/`，实况的静态图和视频一起处理。它不是 Windows 系统回收站。删除前会确认，在“设置 → 回收站”可恢复，恢复需要原硬盘在线且不会覆盖同名文件。文件仍占用磁盘空间，不自动清空。回收记录保存在 `.data/keeplive.sqlite`，请连同硬盘上的回收目录保留；恢复同时找回收藏，但不会重新加入旧分享。多个来源收录同一文件时，所有入口和分享一并撤下。分享访客不能删除、查看回收站或恢复文件。有回收记录的照片来源需要先恢复影像，才能移除，避免失去恢复入口。

原生文件夹选择需要 Windows 登录桌面。以系统服务或其他无桌面方式运行、非 Windows 环境、窗口无法启动或等待超过 3 分钟时，会回退网页选择。关闭添加窗口或改用网页选择会取消尚未完成的系统选择；停止相册服务也会关闭该窗口。原生选择返回的目录仍需通过账号授权范围、其他用户空间和相册数据目录检查。
